**Forward DCF**: value/share = (cell × owner FCF − debt + cash) ÷ shares.

**Reverse DCF**: go down the r column to the two rows whose cells bracket EV ÷ owner FCF, then interpolate g linearly between them. Below the first row, write `< −10%`; above the last row, write `> 40%`.

**Rounding r**: round r to the nearest half-percent column. Write `(table, r rounded to X%)` and mark the result `approx.`
